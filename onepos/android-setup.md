# Set Up OnePOS+ on Android

Use this guide to install and configure OnePOS+ on an Android device.

## Who should do this

- Cashier or Manager setting up a mobile POS terminal

## What you need before starting

- An Android phone or tablet running Android 8 or later
- A RetailHub POS user account with a store assigned
- The OnePOS+ app file or install link provided by RetailHub Pro
- Internet connection during setup

## Steps

### 1. Install the app

Download and install OnePOS+ using the link or file provided by your RetailHub Pro admin or the RetailHub Pro team.

If installing from an APK file:

1. Open `Settings` on your Android phone.
2. Go to `Apps` → `Special app access` → `Install unknown apps`.
3. Allow your file manager or browser to install apps.
4. Open the downloaded APK file and tap `Install`.

### 2. Log in

1. Open OnePOS+.
2. Enter your RetailHub POS email and password.
3. Tap `Sign In`.

Use the same credentials you use on the browser version of RetailHub POS.

### 3. Select your store

1. After signing in, select the store you are assigned to.
2. Confirm the store name matches your location.

### 4. Confirm sync

Check that products appear in the product list. If the list is empty:

- confirm internet connectivity
- confirm your user account has a store assigned in `Users`
- confirm products and stock exist for that store

## Expected result

After setup:

- you can browse products and add them to a cart
- you can accept M-Pesa and cash payments
- sales sync with RetailHub POS and appear in reports

## Good practice

- Keep the app updated when new versions are released
- Log in with a dedicated user account, not a shared one
- If the device will be used offline, ensure a full sync has completed while connected before going offline
