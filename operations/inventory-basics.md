# Inventory Basics

Use `Inventory` to control what you sell and what stock is available in each store.

## Core areas

- product management
- category management
- stock adjustments

## Recommended order

1. Create categories
2. Create products
3. Add or adjust stock
4. Review quantities before sales begin

## Typical tasks

### Add a category

Use categories to organize products for easier filtering and reporting.

### Add a product

Create the product with the correct name, category, and selling price.

### Adjust stock

Use stock adjustments when:

- loading opening stock
- correcting quantity errors
- recording stock changes outside normal sales flow

## Good practice

- Keep product names consistent
- Use stock adjustments carefully and document the reason when possible
- Verify store context before making inventory changes
